# 分流标签

工程技能使用五种规范角色。本文件把规范角色映射到项目议题系统中的实际标签。

| 规范角色 | 本项目标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可由代理执行 |
| `ready-for-human` | `ready-for-human` | 需要人工处理 |
| `wontfix` | `wontfix` | 不会处理 |

技能提到某个规范角色时，使用表中对应的本项目标签。需要调整词汇时，只修改右侧标签列。
