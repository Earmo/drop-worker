# 领域文档

本文件说明工程技能在探索代码库时如何消费领域文档。

## 探索前读取

- 读取仓库根目录的 `CONTEXT.md`。
- 如果存在根目录 `CONTEXT-MAP.md`，则改为读取该文件，并继续读取与任务相关的上下文文件。
- 读取 `docs/adr/` 中与任务相关的架构决策记录。
- 如果这些文件不存在，静默继续，不把缺失本身视为问题。

## 文档布局

当前项目采用单上下文布局：根目录使用一个 `CONTEXT.md`，系统级决策存放在 `docs/adr/`。

## 领域词汇

输出中命名领域概念时，使用 `CONTEXT.md` 定义的术语，不随意改用同义词。所需概念尚未定义时，应先判断是否确有领域词汇缺口。

## ADR 冲突

如果输出与现有 ADR 冲突，必须明确指出冲突及重新讨论该决策的原因，不能静默覆盖。
